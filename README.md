# Excelsior Learning

An AI-powered learning platform that helps students master any subject through interactive lectures and smart flashcards.

**Live Sites:**
- Frontend: https://excelsior-learning.vercel.app/
- Backend API: https://excelsior-academy.fastapicloud.dev/

## What It Does

Excelsior transforms how you learn by leveraging AI to create personalized educational content. Upload your own API key (BYOK model) and generate dynamic lectures with quizzes and flashcards tailored to any topic you're studying.

This idea of mine stemmed from the frustration of getting constantly rate-limited by applications and LLM providers. For me to review my flashcards or get to study another lecture, I needed to wait for hours or another day to reset the app's per user limit. Also, I also wanted to automate the generation of flashcards since I am really lazy (truly).

## Tech Stack

- **Backend:** FastAPI + Python 3.14
- **Database:** PostgreSQL (hosted on Neon)
- **ORM:** SQLModel + Alembic migrations
- **Auth:** JWT tokens
- **LLM Integration:** OpenAI + Google GenAI (via LiteLLM)
- **Frontend:** React + Vite (deployed on Vercel)

## Getting Started Locally

### 1. Clone and Install Dependencies

```bash
cd excelsior-learning
pip install -r requirements.txt
```

### 2. Set Up Environment Variables

Create a `.env` file in the project root with these variables:

You can run it locally on your machine. By default, it will use sqlite for the database, so everything is one the file system. 

```bash

# JWT Secret - generate a secure random string
SECRET_KEY=your-secret-key-here

# key for encrypting API keys
MASTER_KEY=your-master-key-here

# Debug mode (set to True for local dev)
DEBUG=True

```

The SECRET_KEY and MASTER_KEY can be generated by running once.py. You can also generate your own key, just make sure that it is cryptographically strong and safe.

### 3. Run Database Migrations

The backend automatically runs migrations on startup, but you can manually apply them:

```bash
cd src/backend
alembic upgrade head
```

### 4. Start the Backend

For the backend, we use fastapi. You can either run `fastapi run` for starting a production server or `fastapi dev` for development purposes.

```bash
cd src/backend
fastapi dev
```

The API runs at `http://localhost:8000`. Visit `http://localhost:8000/docs` for the interactive API documentation (Swagger UI).

### 5. Start the Frontend (Optional)

The frontend is already deployed, but to run locally:

```bash
cd src/frontend
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

Instead of starting both of these manually, you can use the `run.sh` script. 

## Environment Variables Reference

| Variable | Required | Description |
|----------|----------|-------------|
| `DATABASE_URL` | Yes | PostgreSQL connection string |
| `DATABASE_POOL_URL` | Yes | Connection string with SSL for pooler |
| `SECRET_KEY` | Yes | JWT signing key |
| `DEBUG` | No | Set to `True` for local dev |
| `SENTRY_DSN` | No | Sentry project DSN |

## API Endpoints

- `GET /` - Root endpoint
- `GET /health` - Health check
- `GET /ready` - Readiness check (verifies DB connection)
- `POST /auth/register` - Register new user
- `POST /auth/token` - Login and get JWT token
- `POST /llm/generate-key` - Store user's LLM API key
- `POST /lectures/` - Generate a new lecture
- `GET /lectures/` - List user's lectures
- `GET /lectures/{id}` - Get lecture details
- `POST /decks/` - Generate flashcards from lecture
- `GET /decks/` - List flashcard decks
- `POST /quiz/` - Generate quiz from lecture
- `POST /chat/query` - Chat with AI about a lecture
